# YEBOYBot — правила для Claude Code

## Контекст
- Репозиторій: https://github.com/VolshebniKGG/YEBOYBot
- Робоча гілка: `improvement/probot-readiness`. `main` змінювати/зливати лише за окремим явним дозволом власника.
- Проєкт: Discord-бот Core V2 (Python), Windows 10/11 Control Center (`YEBOYBot.cmd`, PowerShell 5.1, `tools/launcher/`) та legacy-компоненти.
- Відповідай українською; назви файлів, API, команд та програмних ідентифікаторів не перекладай.
- Попередній аудит не є доказом: перевіряй кожен дефект за кодом та тестами.

## Обов'язковий процес
1. Спочатку прочитай `git status --short --branch`, `git remote -v`, `git branch --show-current`; не припускай чистого дерева.
2. Для аудиту — тільки читання, без змін, встановлення залежностей і мережевих дій.
3. Для розробки — покажи план, мінімальний набір змін, ризики та критерії успіху; за потреби делегуй задачі агентам у `.claude/agents/`.
4. Не створюй додаткових гілок без потреби; працюй у `improvement/probot-readiness` або іншій явно погодженій гілці.
5. Після правок виконай `git diff --check`, відповідні тести та lint; звітуй про непроведені тести чесно.
6. `git commit`, `git push` і створення PR — тільки на явне прохання власника. До публікації покажи remote, гілку, перелік файлів і результати тестів.
7. НІКОЛИ не роби push/merge/rebase/reset у `main` без окремого явного дозволу. Без дозволу заборонено `push --force` і `reset --hard`.
8. Стейджи лише перевірені конкретні файли, не застосовуй `git add -A`. Не вмикай auto-merge, не схвалюй власні PR.

## Безпека
- Не читай без необхідності та не публікуй `.env`, `.env.v2`, Discord-токени, API-ключі, бази даних, резервні копії, `config/options.ini` чи локальні логи з секретами.
- Не запускай живого Discord-бота, не тестуй на реальних серверах і не проводь активного сканування без дозволу.
- Не вимикай Defender, SmartScreen, Code Integrity чи інші захисні механізми.
- Для Windows враховуй Unicode/кирилицю, пробіли, OneDrive, довгі шляхи, WinError 5, атомарність і відновлюваність оновлень, exit codes.
- Базова ціль: ZIP → `YEBOYBot.cmd` → меню → Python 3.12 x64 → залежності → перевірки → запуск/стоп/ремонт/оновлення/діагностика без ручного PATH/pip.

## Тести
- Основні тести: `core_v2/tests/`; конфігурація: `core_v2/pytest.ini` та `core_v2/ruff.toml`.
- Лаунчер: `test_bootstrap.py`, `test_windows_setup.py`, `test_launcher_interface.py`, `test_update.py` та суміжні регресії.
- Тести з мережею, секретами або системними змінами — лише після окремого погодження.
- Інструкція з GitHub і агентами: `docs/CLAUDE_CODE_TEAM_UA.md`.
