# Музичний комплект для Windows ZIP

Розпакуйте весь ZIP гілки `improvement/probot-readiness`, відкрийте
`YEBOYBot.cmd` і виберіть початкове встановлення. Панель виконує чотири етапи:

1. Знаходить Python 3.12 x64; за відсутності встановлює через WinGet.
2. Готує `.venv-v2` та Python-бібліотеки.
3. Завантажує й перевіряє портативні FFmpeg і Deno, готує `options.ini`.
4. Перевіряє готовність і відкриває панель керування.

Звичайний GitHub **Code → Download ZIP** містить код завантажувача.
Бінарники завантажуються при першій підготовці; це не повністю офлайновий пакет.
Для музичних архівів потрібно приблизно 158 МБ трафіку та місце для архівів і
розпакованих програм. Python і бібліотеки потребують додаткового завантаження.
FFmpeg/Deno не потребують окремого інсталятора, прав адміністратора або зміни PATH.

## Готовність після встановлення

У новій `.env.v2` встановлено `ENABLE_MUSIC=true`. Наявна конфігурація не
перезаписується: для старої копії зупиніть бот через [3] і виберіть [25] → [1].
Цей пункт сам готує весь музичний комплект і вмикає музику лише після перевірки.
Для підготовки програм бот має бути зупинений.

Після підготовки введіть власний Discord-токен та ID сервера через [12],
налаштуйте синхронізацію команд і запустіть бот через [1]. Приєднайтеся до
голосового каналу й виконайте `/music play query:назва пісні`.
Права Discord, доступність YouTube та власні Spotify API credentials не можуть
бути замінені встановленням програм. Spotify-трек відтворюється через пошук
відповідника; це не пряме відтворення аудіо Spotify.

## Програми та походження

| Компонент | Зафіксована версія | Локальний шлях |
|---|---|---|
| FFmpeg, Gyan Essentials x64 | 9.0.2 | `bin/ffmpeg/ffmpeg.exe` |
| Deno Windows x64 | 2.9.8 | `bin/deno/deno.exe` |

Джерела: [Gyan FFmpeg release](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2)
та [Deno release](https://github.com/denoland/deno/releases/tag/v2.9.8).
Повні URL, розміри та SHA-256 зафіксовано в `tools/portable_media.py`.
Усі файли вихідних архівів, включно з наявними ліцензійними файлами, зберігаються
після розпакування. Завантажувач не вимикає перевірку HTTPS-сертифікатів.

Перед запуском перевіряються розмір і SHA-256 архіву, допустимість шляхів ZIP
та відповідь програми на запит версії. Повторна підготовка перевіряє локальний
файл і версію; якщо все справне, мережа не потрібна. Незнайома папка
`bin/ffmpeg` або `bin/deno` не перезаписується. Несправна власна копія зберігається
як `*.previous-*` перед заміною, лише після успішної перевірки нової копії.

## Якщо підготовка зупинилася

Консоль показує останній етап і залишає помилку видимою. Усуньте причину та
повторіть запуск. При помилці SHA-256 файл не запускається; при мережевому
збої неповний архів не позначається готовим. Токен і дані бота зберігаються.
Не змінюйте контрольні суми для обходу помилки.

Для Linux використовуйте штатний менеджер пакетів для FFmpeg, Deno та libopus.
Автоматичний портативний комплект призначено для Windows x64.
