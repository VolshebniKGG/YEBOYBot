# Довідка та стан модулів у Discord

## Команди

`/help` відкриває приватну українську довідку з розділами, прикладами виклику
та поясненням потрібних дозволів. У меню виберіть розділ; кнопки «Назад» і
«Далі» перемикають сторінки. Можна відразу вказати `/help topic` та `page`.
На сторінці до10 команд, у каталозі до100. Підказка про дозвіл є поясненням:
вона не надає права виконати дію й не замінює перевірку самої команди.

Довідка читає дерево команд поточного процесу з урахуванням команд саме цього
сервера. Вона не публікує команди в Discord. Непідключені музичні команди не
видаються за доступні: розділ пояснює, де перевірити стан. Нові підключені
команди потрапляють до каталогу, невідомі категорії — до «Інше».

Панель діє120 секунд і доступна автору початкового запиту на цьому сервері.
Після завершення повторіть `/help`. При перезапуску панелі не відновлюються:
вони інформаційні й не змінюють налаштувань. Одночасно до100 активних панелей
на процес; за досягнення межі лишається звичайна довідка зі slash-параметрами
розділу й сторінки. Збій надсилання або unload не залишає активну панель без обліку.

`/modules` повертає приватний звіт для поточного сервера. Команда доступна
учасникам сервера й нічого не змінює. Немає читання токена, показу URL БД,
службових шляхів, IDs налаштованих каналів чи чужих користувацьких даних.

## Що означає стан

- Текстовий XP: поточний прапорець `/levels`, готовність і Guild Messages.
- Голосовий XP: той самий прапорець, Voice States, підключений збирач,
  його запущена задача й стан gateway/shard. Аудіо не прослуховується.
- Ранг: підключена `/rank`; для PNG потрібні Attach Files та Embed Links.
- Модерація: підключений модуль; потрібні права й ієрархія залежать від дії.
- Нагадування: фактичний стан планувальника. Це не гарантує доставки кожного
  повідомлення: доступ до каналу та API перевіряються під час виконання.
- Музика: вимкнено, доступна без голосового підключення, підключена до голосу,
  відновлює з'єднання, закривається або стан невідомий. Підключення до голосу
  саме собою не доводить, що зараз відтворюється звук.

Налаштування читаються зі свіжої SQL-відповіді, а не з15-секундного кешу XP.
Читання обмежено3 секундами; при помилці показується «Невідомо». Готовність
перевіряється після читання, щоб не показати старий активний стан після disconnect.
Команда не запускає міграцій, не створює налаштувань і не перевіряє зовнішні джерела.

Автомодерація, привітання, авторолі, панелі ролей, нагороди XP та журнали подій
явно позначаються як непідключені. Наявність полів у БД чи ввімкнення intent
саме собою не активує ці можливості. Message Content Intent не потрібний для
поточного підрахунку XP й не робить незавершену автомодерацію активною.

## Після оновлення на Windows

1. Оновіть код гілки feature/core-v2 через `YEBOYBot.cmd`.
2. Для тестового сервера виберіть **[11]**, збережіть токен через Enter і
   вкажіть ID тестового сервера. Майстер встановить тестову синхронізацію.
3. Перезапустіть через **[2]**, дочекайтеся готовності та перевірте `/help`
   і `/modules` на вибраному сервері.

Публікація залежить від `SYNC_COMMANDS`: `none` не додає команди, `test`
публікує їх лише у вибраному тестовому сервері, `global` — глобально за
окремим налаштуванням власника. Довідка не змінює режим і не очищує старі scope.
Глобальні й тестові команди можуть затіняти одна одну; не видаляйте їх навмання.
Нових залежностей, schema-міграцій або intents для цієї ітерації немає.

## Перевірка

Автоматичні тести використовують реальні метадані discord.py, компоненти View,
SQLite SELECT-only, контрольовані timeout/unload/cancellation та підміни HTTP.
Вони не входять у Discord. Перевірте вручну меню розділів, другу сторінку
модерації, завершення панелі й зміну `/levels` → `/modules` на тестовому сервері.
Точні результати — у [статусі](CORE_V2_STATUS_UA.md) та CI за поточним SHA.
