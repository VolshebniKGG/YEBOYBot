# Панель керування та префікс !

`YEBOYBot.cmd` відкриває оновлену українську панель: керування ботом,
налаштування, дані/резервні копії та обслуговування. Пункти показано в одній
колонці за зростанням номерів; номери дій збережені. Довгі підписи переносяться
відповідно до ширини вікна. `[0]` закриває лише панель,
а `[3]` зупиняє бот. Для музики використовуйте `[25]`.

## Увімкнення команд !

1. У [Discord Developer Portal](https://discord.com/developers/applications)
   відкрийте свій застосунок → **Bot → Privileged Gateway Intents → Message Content Intent**.
2. Відкрийте `YEBOYBot.cmd` → **[11]** або **[12]**. Збережіть токен та ID через Enter,
   а на запит «Команди !» введіть `true`.
3. Перезапустіть через **[2]**. Перевірте `/modules` → «Префікс !».

Еквівалентне ручне налаштування у `.env.v2`: `ENABLE_PREFIX_COMMANDS=true`.
Змінні середовища мають пріоритет. Початкове значення — `false`, щоб наявний
бот не втрачав підключення через неувімкнений привілейований intent.
Увімкнення в коді не вмикає дозвіл у Portal. Slash-команди працюють і без цього intent.

## Як користуватися

Команди `!help`, `!modules` і `!queue` виконуються без додаткової кнопки:
бот надсилає приватну довідку або статус модулів у DM автору, перевіряючи
актуальне членство та доступ до початкового каналу. Для розділу довідки
використовуйте `!help music` або `!help rank`. У DM довідка статична:
інтерактивне перемикання розділів доступне через `/help`.

Якщо особисті повідомлення Discord закрито або доставку не підтверджено,
бот пропонує колишню одноразову кнопку лише автору — приватність не
послаблюється. Інші `!` команди поки зберігають кнопку: вони викликають
справжню Interaction й той самий обробник, що й slash-команди. Додаткове
натискання потрібне для збереження ephemeral-відповідей. Команди з власним
підтвердженням, як очищення, зберігають його.

| Приклад | Дія |
|---|---|
| `!help` | Довідка |
| `!modules` | Стан модулів |
| `!rank` | Власний ранг |
| `!play Виконавець назва пісні` | Замовити музику |
| `!music play https://music.youtube.com/watch?v=ID` | Повна форма музичної команди |
| `!queue` | Черга |
| `!remove 2` | Видалити своє друге замовлення (або чуже з дозволом «Керувати сервером») |
| `!shuffle` | Перемішати чергу очікування (потрібен дозвіл «Керувати сервером»; одноразова кнопка) |
| `!skip` | Пропустити трек із перевіркою прав |
| `!stop` | Зупинити музику із перевіркою прав |
| `!levels true` | Увімкнути XP, якщо є потрібні права |

Аргументи позиційні, у порядку параметрів slash-команди. Текст із пробілами
можна взяти в подвійні лапки; останній текстовий аргумент приймає решту рядка.
Учасників, ролі та канали вказуйте згадкою або числовим ID. Для пропуску
необов'язкового аргументу використовуйте `-`. Значення `true`/`false`
означають увімкнення/вимкнення. Невідомі команди не запускаються.

Ваш початковий текст `!команда ...` видимий у каналі: не пишіть у ньому секрети.
Бот не дублює аргументи в публічній кнопці. Для чутливих аргументів краще `/`.

## Права та обмеження

Префікс — окремий вхід до команд, який власник явно вмикає. Перевіряються
права за замовчуванням і перевірки самого обробника, включно з ієрархією
та REST-перевірками там, де вони реалізовані. Персональні дозволи/заборони
slash-команд у **Server Settings → Integrations** не копіюються в цей вхід.
Якщо політика сервера залежить від цих винятків, залиште префікс вимкненим
і користуйтеся slash-командами. Префікс не надає відсутніх адміністративних прав.

Команди не працюють у DM, від інших ботів чи webhook. AutoMod перевіряє
повідомлення перед префіксом; команди не приносять XP. Кількість активних
кнопок і частота запитів обмежені. Після перезапуску старі кнопки треба створити
повторно новою командою.

Ліміти: 256 активних запитів загалом, 16 кнопок на сервер, пауза 3 секунди
між текстовими запитами одного учасника та 2 хвилини дії кнопки. Визначення
учасника/каналу через Discord обмежене 2 секундами; при повільній відповіді
може знадобитися нова спроба. Кнопки не відновлюються після перезапуску.

Поточний ProBot за [офіційним FAQ](https://docs.probot.io/docs/getting-started/faq)
використовує slash-команди й aliases. Вхід `!` у YEBOYBot додано за вашим запитом;
це не твердження про повну відповідність ProBot.
