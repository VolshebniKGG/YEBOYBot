# Windows CMD Launcher (рання версія)

У гілці feature/core-v2 додано YEBOYBot.cmd. Запустіть його подвійним натисканням у Windows 10/11. Потрібен встановлений Python 3.12 з Python Launcher (py). Якщо .venv-v2 відсутнє, запускається наявний install_v2.bat, який створює середовище, встановлює core_v2/requirements.txt та створює .env.v2 з прикладу.

Меню має дії: [1] запуск Core V2 у поточному вікні (Ctrl+C зупиняє), [4] offline doctor, [5] pip install залежностей, [7] SQLite backup API, [9] останні 60 рядків журналу, [11] створення .env.v2 без перезапису, [12] початкове налаштування й doctor, [0] вихід.

Відредагуйте .env.v2 вручну (DISCORD_TOKEN, TEST_GUILD_ID, SYNC_COMMANDS=test) і не публікуйте файл. Меню не показує ще не реалізовані дії [2], [3], [6], [8], [10]. Зупинка доступна лише Ctrl+C у поточному вікні. Не запускайте іншу копію бота зі старого каталогу чи з тим самим токеном.

Важливо: CMD Launcher ще НЕ пройшов Windows CI чи ручний запуск. Зокрема перевірка відсутності Python, оновлення коду з GitHub, автоматичне відновлення БД, супервізор, перевірка readiness і керування окремим фоновим процесом залишаються невиконаними. Резервування [7] підтримує лише SQLite. Наразі це перша ітерація, не завершений P0/P1.
