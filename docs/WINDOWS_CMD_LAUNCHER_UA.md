# Керований Windows CMD запуск
Потрібен Python 3.12 з Python Launcher. Відкрийте YEBOYBot.cmd.
Віртуальне середовище .venv-v2 створює наявний install_v2.bat.
[11] створює конфігурацію без перезапису та відкриває Блокнот.
Впишіть DISCORD_TOKEN, TEST_GUILD_ID, SYNC_COMMANDS=test.
[1] запускає один процес із фоновими задачами. Готовність показується лише після Discord ready.
[2] виконує коректну зупинку та новий запуск; [3] зупиняє через запит із nonce.
[0] закриває меню, але залишає бот працювати. Для зупинки використовуйте [3].
Можна повторно відкрити меню; дубль блокується OS lock.
Heartbeat оновлюється щосекунди. Після 10 секунд без оновлення показується «Не відповідає».
Завислий процес автоматично не вбивається; перезапуск не запускає дубль.

[4] offline doctor, [5] залежності, [7] SQLite backup, [9] журнал.
Автоматичне оновлення Git, відновлення backup з меню та crash-restart supervisor ще не реалізовані.
Після аварії перевірте журнал і запустіть [1]; цикл автоматичних перезапусків відсутній.
SQLite backup у цьому меню поки використовує стандартний шлях data/v2/yeboy.db.
Для нестандартної DATABASE_URL резервування з меню не використовуйте.
Windows smoke тест перевіряє меню з кириличного шляху з пробілами.
Живе Discord-підключення потребує тесту власником; без токена воно не перевірене.
